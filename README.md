# DevSphere — Interactive Portfolio + Simple Crypto Dashboard

A front-end showcase using HTML, CSS, JS, and images only:
- Three.js 3D hero
- GSAP scroll-driven timeline
- Chart.js dashboard with real-time crypto data (CoinGecko)
- Theme toggle with persistence
- Canvas mini-game

## About
DevSphere is a lightweight, experimental front‑end project designed to demonstrate modern web techniques in a playful yet professional way. It combines interactive visuals, real‑time data, and creative UI elements into a single portfolio‑style experience.  
This project is not intended for production use, but rather as a learning exercise and a showcase of skills in animation, visualization, and front‑end engineering.

## Structure
See folder tree in the project root. All scripts are modular and loaded via CDN or in `scripts/`.

## Run
Open `index.html` or `dashboard.html` directly. For local testing, use a static server:
- Python: `python -m http.server 8080`
- Node: `npx serve`

## Customize
- Edit content in `index.html` timeline cards and projects grid.
- Replace images in `assets/images`.
- Add icons in `assets/icons`.
- Tweak theme in `styles/style.css`.

## Notes
No backend required. APIs are public. Rate limits may apply.
